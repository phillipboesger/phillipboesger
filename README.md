### What I do

- **Polarion, from spec to production:** extensions in Java, REST, Velocity and workflow scripts, with CI/CD and automated release documentation.
- **AI agents and MCP:** agents that work on real Polarion data instead of copy and paste.
- **AI enablement:** coaching on real tickets, so teams use Copilot and agents properly.
- **Sharing what works:** tools, guides and write-ups that other teams can reuse.
